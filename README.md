# 🧸 FURBALICIOUS FURBZ – Custom Shopify Theme

> A custom-coded Shopify theme for **Furbalicious Furbz**, blending collector-grade Furby drops, cursed couture, and hypnotic storefront aesthetics.

---

## 🌀 What is this?

This repo contains the live theme powering our **Furbalicious Furbz** storefront – a hand-crafted Shopify experience designed to:
- Showcase **sealed collector Furbys**, longboys, cursed purses, hybrids, and one-off mods.
- Support our unique drop campaigns and lore-infused product listings.
- Reflect the wild, weird, and whimsical vibe of the Furbycore community.

---

## 🎨 Tech Stack

- **Shopify (Liquid)** – base template system.
- **Shopify Dawn** – forked as a starting point.
- **Custom CSS / JS** – for branding, animations, and behavior tweaks.
- **Optional TailwindCSS / SCSS** – modular styles (future).
- **GitHub integration** – continuous theme deployment via Shopify GitHub App.

---

## 📦 How to Use

### 🔗 Connected to Shopify?
If this repo is linked via Shopify’s GitHub integration:
1. Any `main` branch push will auto-deploy to your theme.
2. To preview changes, use a development theme in Shopify admin.

### 🛠 Dev Setup (Optional)
For local testing (via Shopify CLI):

```bash
npm install -g @shopify/cli
shopify theme dev
